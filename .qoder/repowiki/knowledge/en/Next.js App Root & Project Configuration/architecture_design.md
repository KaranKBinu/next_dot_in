This leaf is the project root; all runtime logic lives under sibling directories (src/, prisma/). The app is configured as a Next.js 16 App Router project (`next.config.ts` exposes `ADMIN_SESSION_TOKEN` and `ADMIN_PASSWORD` to the Edge runtime), uses TypeScript with `bundler` module resolution and `@/*` → `./src/*` path aliases (`tsconfig.json`), and runs ESLint via the flat config format (`eslint.config.mjs`) built on `eslint-config-next`. Styling is handled by Tailwind CSS v4 through `@tailwindcss/postcss` (`postcss.config.mjs`). Database access is declared in `prisma/config.ts` pointing at `prisma/schema.prisma` with a Neon serverless adapter (`@prisma/adapter-neon`, `@neondatabase/serverless`) and a seed script at `prisma/seed.js`. A single global Edge `middleware.ts` enforces admin authentication by checking an `admin_session` cookie against `ADMIN_SESSION_TOKEN`, redirecting unauthenticated requests to `/admin/login?from=<path>`; it matches `/admin` and all sub-paths. Runtime secrets are loaded via `dotenv` in Prisma's config file.
